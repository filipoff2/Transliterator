# Czech Character to Sound Mapping (for Font / Transliteration Projects)

## Quick Lookup Table

```text
č -> cz
š -> sz
ž -> ż
ř -> rż
ň -> ń
ď -> dź
ť -> ć
ě -> ie

á -> a
é -> e
í -> i
ó -> o
ú -> u
ů -> u
ý -> y
```

## Most Characteristic Czech Letters

```text
č
š
ž
ř
ě
```

Among these, **ř** is uniquely Czech and has no exact equivalent in Polish.
