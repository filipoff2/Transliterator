# Polish to Czech Approximate Sound Mapping

Purpose: approximate Polish special letters using Czech sounds/letters.

## Mapping

```text
ą -> on
ć -> č
ę -> en
ł -> l
ń -> ň
ó -> u
ś -> š
ź -> ž
ż -> ž
```

## Examples

```text
Łukasz      -> Lukaš
mąż         -> monž
kąt         -> kont
język       -> jenzyk
koń         -> koň
góra        -> gura
śnieg       -> šněg
źle         -> žle
żaba        -> žaba
ćma         -> čma
```

## Notes

- ł has no direct Czech equivalent; using l is the simplest approximation.
- ą has no Czech equivalent; on is the closest practical representation.
- ę has no Czech equivalent; en is the closest practical representation.
